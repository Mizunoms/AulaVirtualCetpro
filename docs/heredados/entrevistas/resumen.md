## Problemática principal

1. **Todo pasa por WhatsApp.** Tareas, entregas y avisos van por chat; las fotos y archivos quedan
   dispersos y cuesta ordenarlos y calificarlos.
2. **Las plataformas les parecen complicadas.** Es el mayor riesgo: si el sistema es enredado, no se usará.
3. **Todo es desde el celular**, tanto docentes como alumnos.
4. **Cursos prácticos:** las entregas son fotos del trabajo, hojas de operaciones y diagramas.
5. **Asistencia y notas en papel**; los reportes a dirección se arman a mano en Excel cada 3 meses / fin de módulo.
6. **Cada docente califica distinto** (0–20, rúbrica, aprobado/desaprobado) y maneja las entregas tardías
   de forma diferente (acepta / acepta con menos nota / no acepta).

## Cómo nos adaptamos

| Hallazgo | Decisión en el sistema |
|---|---|
| Uso solo desde celular | Diseño mobile-first, botones grandes, flujos cortos |
| Plataformas "complicadas" | Interfaz mínima: dejar tarea → ver entregas → calificar en pocos toques |
| Entregas por foto | Subida directa desde la cámara del celular, además de PDF/Word |
| Dependencia de WhatsApp | Botón "Compartir en WhatsApp" con el enlace de la tarea/anuncio; el sistema guarda las entregas |
| Distintas políticas de tardías | Configuración por tarea: no acepta / acepta / acepta con penalidad |
| Distintas formas de calificar | Por tarea: nota 0–20, rúbrica o aprobado/desaprobado |
| Tareas grupales | Soporte para tareas grupales |
| Todas toman exámenes | Subir prioridad de cuestionarios en línea |
| Asistencia en papel | Registro de asistencia en una sola pantalla |
| Reportes manuales a dirección | Exportar a Excel con el formato oficial de dirección |
| Piden orientación | Capacitación práctica + videos cortos por función |
